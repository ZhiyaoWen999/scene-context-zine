# Research Lineage and Transferable Operators

Use this file for research and route development. Treat names and works as historical evidence, not prompt tokens. Translate each reference into formal, source-derived operations and create an original result.

## 1. Photography plus graphic structure

Herbert Matter's Swiss travel posters demonstrate that photography, photomontage, typography, scale shifts, and geometric structure can coexist while the destination stays recognizable. The transferable operator is: **keep a place-defining photographic anchor, then derive the graphic plane and type hierarchy from its geometry**.

- Source: [MoMA — The Graphic Designs of Herbert Matter](https://www.moma.org/calendar/exhibitions/340/installation_images/27378)

Use this research mainly for Graphic Scene Poster.

## 2. Fragmentation without loss of place

Photographic composites and collages can accumulate multiple moments and viewpoints instead of reducing the scene to one decisive crop. The transferable operator is: **reassemble faithful source crops so fragmentation expands attention while spatial identity remains legible**.

- Source: [Getty — Pearblossom Hwy., 11–18th April 1986, #2](https://www.getty.edu/art/collection/objects/105374/david-hockney-pearblossom-hwy-11-18th-april-1986-2-british-april-11-18-1986/)
- Context: [Getty — photographic explorations of time and perspective](https://www.getty.edu/art/exhibitions/hockney_birthday/)

Use this research mainly for Multi-frame Joiner. Do not ask the image model to imitate the named artist.

## 3. Context as the subject

Lived-in interiors show that possessions, density, wear, arrangement, and ordinary background are not visual noise; they are evidence about the occupant and place. The transferable operator is: **preserve meaningful complexity, compress only repetition, and never auto-clean the scene**.

- Source: [Apartamento — Kyoichi Tsuzuki's Tokyo Style](https://www.apartamentomagazine.com/archive/kyoichi-tsuzukis-tokyo-style-1993/)
- Publication history: [Chikuma — TOKYO STYLE revived](https://www.webchikuma.com/n/n7f6b7ef0564e?hl=en)

Use this research across all routes, especially interiors.

## 4. Content-derived grid

Swiss editorial design supplies asymmetry, grid, typography, and photographic hierarchy, but the important transferable principle is that the **content must be the starting point for the graphic solution**.

- Source: [Cooper Hewitt — A Harmony of Contrasts](https://www.cooperhewitt.org/2018/08/05/aharmonyofcontrasts/)

Use this research mainly for Documentary Editorial and Graphic Scene Poster.

## 5. Dynamic photographic recombination

Photocollage treats photography as graphic material that can be altered, replicated, and recombined. Abrupt scale shifts and diagonals can create energy without inventing unrelated imagery. The transferable operator is: **recombine real source material along an existing motion, gaze, façade, or path**.

- Source: [MoMA — Rodchenko: Photocollage](https://www.moma.org/interactives/exhibitions/1998/rodchenko/texts/photocollage.html)

Use this research as a high-energy option within Graphic Scene Poster or Multi-frame Joiner.

## 6. Print process as material, not filter

RISO-like stencil duplication is useful for bold color, layering, texture, stencilling, and color mixing. Its transferable operator is: **apply a print behavior to one source-derived layer instead of forcing the whole image through a global effect**.

- Source: [V&A — RISO Printed Zines](https://www.vam.ac.uk/event/8vakyGm1/riso-printed-zines-ks3-summer-2026)

Use this research as a selective material module in any route.

## 7. Contact sheet and memory archive

A contact-sheet or photobook page shifts the goal from a single poster toward a visual record: whole scene, detail, person, material, light, and supplied metadata can form a sequence. The transferable operator is: **turn one photograph into a small archive of attention without fabricating additional moments**.

Use this as the Contact-sheet memory strip secondary technique.

## 8. Travel diary and ephemera

Place, date, weather, ticket fragments, menus, maps, and a remembered sentence can make a page more specific when they are real. The transferable operator is: **treat verified metadata and physical traces as part of the scene rather than as decorative pseudo-editorial labeling**.

Use this as the Ephemera layer secondary technique. Ask for missing facts only when the user specifically wants factual metadata and it cannot be read from the source; otherwise omit them.

## 9. Synthesis rules

Combine references by problem, not by surface resemblance:

- Need photography and design to coexist while preserving location → photographic anchor + content-derived grid.
- Need cutting without losing reality → faithful multi-frame source assembly.
- Need background to remain meaningful → lived-in context and semantic detail map.
- Need more energy → source-axis scale shifts and dynamic recombination.
- Need tactile print character → one localized source-derived print layer.
- Need travel memory rather than poster → contact-sheet or ephemera layer with verified metadata.

Never place historical names in a generation prompt. Encode crop, scale, grid, overlap, material, color, and preservation behavior directly.
